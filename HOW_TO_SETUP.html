What is this system?

This is the Abhinav Group Email Signature Generator. It automatically creates a professional HTML email signature for every employee, matching the official Abhinav Group signature design — with social media icons added below.

What each signature includes: • Company logo • Employee name & designation • Phone, email, website • Company address • Clickable social icons (Website, Facebook, Instagram, LinkedIn, YouTube)

How to generate ALL signatures (for admins)

  • Open the Email Signature folder
    Navigate to the folder where this file is located on your computer.
  • Double-click run_me.bat
    A black window will appear and automatically generate all signatures. It closes when done and opens a preview in your browser.
  • Check the preview
    Your browser will open preview_all.html showing all signatures. Verify each one looks correct.
  • Distribute individual files
    Each employee's signature is saved as output\EmployeeName.html. Share the correct file with each person and they follow the setup steps below.
Important: Every time you run run_me.bat, it reads the latest data from Excel and regenerates all signatures. This means ALL updates (name, phone, designation changes) are automatically applied.

Update an existing employee's details

  • Open employees\employees.xlsx
  • Find the employee's row
    Scroll through the list or use Ctrl+F to search.
  • Edit the cell(s) that changed
    Click on the cell, delete the old value, type the new one. You can change name, designation, phone, or email.
  • Save (Ctrl + S) and close Excel
  • Double-click run_me.bat
    The signature file is overwritten automatically with the new details. Share the updated file with the employee.
Note: If the employee's NAME changed, their old .html file in output\ will remain. You can safely delete it — the new one with the updated name will be there.

Remove an employee

  • Open employees\employees.xlsx
  • Right-click on their row number and select "Delete"
    This removes the entire row. Do not just clear the cells — delete the whole row.
  • Save and close Excel, then run run_me.bat
  • Delete their old signature file from output\
    Find output\EmployeeName.html and delete it manually.

Gmail Setting up your signature

Before you start: Get your signature file from your admin. It will be named something like YourName.html and is located in the output\ folder.

Method 1 — Copy & Paste (Recommended — Works on all devices)

  • Open your signature file in a web browser
    Double-click your output\YourName.html file. It will open in Chrome, Edge, or Firefox.
  • Select ALL and copy
    Press Ctrl + A (select all), then Ctrl + C (copy). You should see the entire signature highlighted in blue.
  • Open Gmail Settings
    Go to gmail.com → Click the gear icon (⚙) in top-right → Click "See all settings".
  • Go to the Signature section
    Stay on the General tab → Scroll down until you see the "Signature" section.
  • Create a new signature
    Click "+ Create new" → Give it a name like "Abhinav Group" → Click Create.
  • Paste your signature
    Click inside the signature text box → Press Ctrl + V to paste. Your signature with logo and icons should appear.
  • Set as default and save
    Under "Signature defaults", select your signature for both "For new emails" and "For replies/forwards" → Scroll to the bottom → Click "Save Changes".
Done! Send yourself a test email to verify the signature appears correctly with all social icons.

Outlook Setting up your signature (Desktop)

For Outlook 2016, 2019, 2021 and Microsoft 365

  • Open your signature HTML file in a browser
    Double-click output\YourName.html — it opens in Chrome or Edge.
  • Copy the signature (Ctrl + A, then Ctrl + C)
  • Open Outlook → Go to File → Options
  • Click "Mail" → then "Signatures..."
  • Click "New", name it "Abhinav Group", click OK
  • In the signature editing box, paste with Ctrl + V
    Your signature should appear with the logo, contact info, and social icons.
  • Set as default for New messages and Replies
    On the right side, under "Choose default signature", select "Abhinav Group" for both dropdowns.
  • Click OK to save
Outlook Note: Outlook may show a security warning about images. Click "Enable" or "Always allow" to display the signature correctly. Since all images are embedded directly in the file (no external links), this is completely safe.

Outlook Setting up on Outlook Web (Browser)

  • Go to outlook.com or office.com and sign in
  • Click the gear icon (Settings) → "View all Outlook settings"
  • Go to Mail → Compose and reply → Email signature
  • Open your HTML file in a browser, copy it (Ctrl+A, Ctrl+C), paste here (Ctrl+V)
  • Enable "Automatically include my signature" for new messages and replies
  • Click Save

Setting up signature on Mobile (Android / iPhone)

Important note about mobile email apps: Most mobile email apps (Gmail app, Outlook app) have limited support for HTML signatures with images. The recommended approach is to set up the signature on your desktop/laptop first, and the mobile app will sync it automatically.

Gmail App (Android & iPhone) — Recommended approach

  • Set up the signature on your desktop Gmail first
    Follow the Gmail steps in the previous tab on a computer. The signature will then appear on desktop.
  • On your phone — Gmail app uses a simple text signature
    Open Gmail app → Menu (three lines) → Settings → Your email → Signature settings. Here you can only add plain text. Type your name, title, and phone number as plain text for mobile replies.

Outlook Mobile App

  • Open Outlook app → Tap your profile picture → Settings (gear icon)
  • Scroll down and tap "Signature"
  • Type a simple text signature for mobile
    Example:
    Avdhut Chakradhar
    Purchase Manager, Abhinav Group
    +91 72195 50051
    www.abhinavgroup.co.in
Best Practice: Use the full HTML signature (with logo and icons) for emails sent from your laptop/desktop. For emails replied from your phone, a simple text signature is standard practice — recipients understand this.

Frequently Asked Questions

Q: The logo or icons are not showing up in Gmail

All images are embedded directly inside the HTML file (no external links), so they should always appear. Make sure you copied the entire signature from the browser (Ctrl+A, Ctrl+C) and pasted it in Gmail's signature editor.

Q: My signature looks different in Outlook vs Gmail

This is normal. Outlook and Gmail render HTML slightly differently. The signature is designed to look correct in both. Minor spacing differences are expected and acceptable.

Q: Can I edit the signature myself?

No — do not edit the HTML file manually. All changes should be made in the Excel file (employees\employees.xlsx), then run run_me.bat to regenerate. This keeps all signatures consistent and correct.

Q: What if someone leaves the company?

Delete their row from the Excel file → run run_me.bat → manually delete their .html file from the output\ folder.

Q: What if a social media link changes?

Open generate_signatures.py in Notepad. Find the SOCIAL_LINKS section near the top. Update the URL for the changed platform. Save the file. Run run_me.bat.

Q: Can this work without internet?

Yes — completely! All images are embedded in the HTML files. No internet connection is needed to generate or use the signatures.

Q: The run_me.bat says "Python not found"

You need to install Python once. Visit https://www.python.org/downloads/, download the latest version, and during installation, check the box that says "Add Python to PATH". Then restart your computer and try again.

Q: Do I need to set this up again every time?

No! Once a signature is set up in Gmail or Outlook, it stays there permanently. You only need to update it if details change (which is very easy — just redo the paste step with the new file).
